# Creative Direction

Read `../_references/vj-practice.md` first.

Do not wait for finished prose. Develop three materially different worlds in parallel and request visible probes as soon as each has a contradiction and visual verb.

For each world:

1. Define contradiction, verb, restrained palette, material behavior, light source, spatial rule, and forbidden cliché.
2. Request at least anchor, subject, environment, and rupture probes; add texture and loop seed when useful.
3. Keep each prompt narrow enough to test one idea.
4. Surface each probe immediately as `generating`, then `candidate` or `rejected`.
5. Inspect media. Replace a failed role with targeted direction rather than rewriting the whole world.

The artist chooses from visible media. Preserve selected probe IDs and prompts as lineage. For “generate more,” change one major variable while preserving identity. Never return a prose-only treatment.
