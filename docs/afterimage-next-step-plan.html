01 / Target

Prove the agency, not a feature catalog.

The wedge is deliberately narrow: AfterImage must take one real artist from raw song to finished visual. Breadth comes only after that run is reliable, resumable, and beautiful.

The product

A creative agency in one focused workspace.

The artist makes creative decisions. The agency handles model selection, shot prompts, retries, Hydra layering, editing, render settings, and quality control.

  • Artifact-first: the video is always the hero
  • One clear decision at every approval point
  • Agency work is visible as meaningful production events
Win condition

Clean run, no backstage rescue.

A fresh user can complete the pipeline from the deployed app and download a coherent master.

  • 20–30 second final master
  • Three distinct director treatments
  • One revision produces version 2
  • Reload resumes the correct state
Not now

Keep the surface small.

These are valuable add-ons, but each creates a second product before the first one works.

  • No manual timeline editor
  • No full-song or album workflow
  • No live-show controller
  • No collaboration, billing, or marketplace
  • No vertical/square exports yet
AI as Agency proof

Five specialist roles create durable artifacts and hand them off: Music Analyst → Creative Director → Video Producer → Motion Editor → QA Director. The UI presents one calm “AfterImage Producer,” while the activity feed proves delegation, judgment, retries, and a human approval boundary.

04 / Capabilities

What must be fixed before add-ons.

P0 is the actual end-to-end contract. P1 hardens that path. “Later” is explicitly kept outside the build until the contract passes.

P0

Foundation + contracts

Scaffold one repo, define typed production artifacts, stage transitions, environment checks, and a seed project.

Gate: a fake production moves through every state and survives reload.
P0

Media intake

Upload audio, lyrics, cover art and optional references with progress, validation, durable asset IDs, and R2 storage.

Gate: a 100MB song uploads once, resumes safely, and plays back.
P0

Music intelligence

Use ffprobe + Meyda to map duration, BPM, beats, energy, sections, peaks, and a chosen 20–30s excerpt.

Gate: the excerpt and beat markers are deterministic on rerun.
P0

Hermes production agency

Five roles hand off structured artifacts. Hermes emits human-readable events, pauses for direction approval, and resumes.

Gate: the run visibly delegates and cannot skip the approval boundary.
P0

Creative direction

Generate three meaningfully different treatments: narrative, visual rules, palette, shot intent, and forbidden moves.

Gate: a user can explain the difference without reading the prompts.
P0

Video production adapter

Wrap ElevenLabs Image & Video behind one narrow shot API. Lock one proven model path; retries preserve shot intent.

Gate: three usable shots return with IDs, cost, duration, and lineage.
P0

Hydra visual layer

Extract Uplauz’s runtime/catalog, choose one preset from the treatment, drive it from the music map, and capture deterministically.

Gate: the same feature timeline produces the same overlay frames.
P0

Composition + render

Remotion composes shots, transitions, Hydra overlay and source audio. FFmpeg inspects and produces the delivery master.

Gate: one command creates the correct 16:9 H.264/AAC master.
P0

Review + one revision

Play the master, capture natural-language feedback, map it to affected shots/layers, and preserve version 1.

Gate: version 2 changes the requested seam without rebuilding unrelated work.
P1

QA + recovery

Validate missing frames, corrupt assets, duration, codec, loudness, FPS, strobe/luminance, and retry ceilings.

Gate: an injected failed shot recovers or ends with a useful action.
P1

Cost + run observability

Track model cost, attempts, stage latency, artifact lineage, and render logs without exposing an enterprise dashboard.

Gate: every final frame can be traced to a shot, prompt, model, and run.
Later

Add-on surface

Vertical/square derivatives, full songs, 3D worlds, live-reactive companion, collaboration, artist memory, billing, and templates.

Rule: none begin before the golden production passes twice from clean state.
05 / Architecture

Simple app. Deep production engine.

Deployment boundary

Vercel serves the Next.js product at afterimage.space; it does not run long FFmpeg, Chromium, Hermes, or model jobs. Those stay in the production worker, report progress through Convex, and publish binaries to R2. This keeps deploys fast and avoids pretending serverless functions are a render queue.

07 / Build order

Build the tracer bullet, then replace the weak links.

The first milestone crosses the whole system with typed placeholders. Every phase after that swaps in real production capability without changing the user journey.

01

Scaffold the production spine

Next.js App Router, Convex, R2 adapter, typed artifacts, stage machine, seed production, environment validator, and Vercel project link. Exit: fake run reaches “delivered” on a preview deployment.

02

Render something real

Upload one song, analyze it, select the excerpt, and produce a fixed Remotion composition with source audio. Exit: downloaded master has correct audio and duration.

03

Make the agency visible

Wire Hermes roles, structured artifacts, event feed, treatment generation, approval pause, and resume. Exit: three directions arrive and only the selected one proceeds.

04

Replace placeholder shots

Integrate one ElevenLabs video model path, generation polling, lineage, cost, retries, and three-shot plan. Exit: the master is built from generated shots.

05

Add the AfterImage signature

Extract the Uplauz Hydra runtime/catalog, bind one preset to the music map, capture it, and composite it. Exit: visuals audibly respond and rerender deterministically.

06

Close the loop + ship

Review UI, one scoped revision, version comparison, QA gates, recovery states, export, golden-song rehearsal, and production-domain assignment. Exit: two clean runs complete at afterimage.space without manual repair.

08 / Done means

A proof checklist, not a feeling.

The next step is complete only when every statement below is demonstrably true.

✓
Cold start worksA new browser can create a production without seeded database edits or local file surgery.
✓
State survivesRefresh, reconnect, and worker restart return to the correct stage without duplicate generations.
✓
Agency is legibleThe demo shows specialist handoffs, one approval pause, one rejection/retry, and one final decision.
✓
Master is valid1920×1080, 20–30s, H.264/AAC, correct audio segment, playable in browser and downloadable.
✓
Revision is scopedVersion 2 preserves version 1 and changes only the requested shot, layer, or direction.
✓
Failure is survivableA bad generation, timeout, or render error retries safely or offers one clear recovery action.
✓
Creative quality holdsThe three directions are distinct and the selected master feels intentionally cut to the song.
✓
No hidden rescueThe demo operator never opens Remotion, FFmpeg, R2, Convex, or a model console to finish.
